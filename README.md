# Jm3etna
  Jm3etna is a platform for connecting volunteers with humanitarian initiatives, such as free Iftar (Rahma) restaurants, which rely on community support but often face logistical and communication challenges. It streamlines volunteer coordination, enhances collaboration, and helps organizations manage resources efficiently to maximize their impact.
  The frontend branch contains the user interface and client-side logic (frontend), while the backend branch holds the server-side functionalities and database operations(backend). However, these two components are not yet integrated, meaning the frontend does not currently communicate with the backend.U can run each one separately
